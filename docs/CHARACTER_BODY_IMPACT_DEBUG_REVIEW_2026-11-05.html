몸통 밀침 캡슐 디버그 표시 검토

2026-11-05 · 사용자 요청: 몸통 밀침 판정 캡슐을 디버그 라인으로 표시.

검토 가능한 후보. Debug 빌드와 밀침 전용 테스트, 숨김 실행의 GPU 화면 확인은 통과했다. 전체 테스트에는 아래 실패가 남아 있다. AGENTS.md의 사용자 검토·명시적 승인 전 완료 확정 및 커밋 금지 규칙에 따라 커밋하지 않았다.

변경 내용과 흐름

기존 ModelViewer → RagdollImpactTest::BuildLines → RenderDebugLines 경로에 몸통 캡슐 윤곽을 추가했다. 월드의 이동 가능한 캐릭터 중 몸통 밀침이 활성화된 캐릭터를 대상으로 현재 물리 몸의 GetCharacterImpactCapsule 결과를 읽는다. 접촉 여유(contactSkin)를 더한 반지름으로 100개의 청록색 선분을 만들고, 기존 깊이 무시 오버레이 경로에 전달한다. 정지 더미는 밀침 판정의 수신자이므로 자체 판정 캡슐을 표시하지 않는다.

‘PARS - 더미 충격 테스트 → 캐릭터 몸통 밀침 → 몸통 밀침 캡슐 표시’ 체크박스를 추가했으며 기본값은 켜짐이다. 표시 상태는 뷰어에만 저장된다. 현재 위치의 캡슐을 그리며, 이동 스윕 전체 궤적·이동 목표 오프셋·재접촉 유지용 추가 여유는 표시하지 않는다. 기존 노란 이동 캡슐과 구분된다.

물리 제어식·충격량·PD·토크 상한·PA·애니메이션·시험 입력은 변경하지 않았다. RememberPhysicsAsset 선언은 역할별 배치 규약에 맞춰 Getter/Setter 구간으로 이동했으며 접근 수준과 동작은 같다. 새 bool 멤버는 기존 bool 멤버 뒤에 배치했다.

한계 및 판단

개선: 보이지 않던 현재 몸통 밀침 영역을 실제 렌더링에서 확인할 수 있다. 표시 대상마다 프레임당 형상 경계 계산과 100개 선분 생성이 추가된다. 성능 수치는 별도 계측하지 않았다. 눈에 보이는 표시 문제는 이번 기본 바닥 캡처에서 발견하지 않았다.

물리 동작 비교는 수행하지 않았다. 골반·발·팔다리 추종 오차의 평균/RMS/최대/발생 시점, 발 떨림·미끄러짐·자세 붕괴·충돌 후 제동 및 복구, 요구/적용 토크·포화 지속 시간은 측정하지 않았으며 개선 또는 무회귀를 주장하지 않는다. 전용 테스트 통과와 정지 화면은 그러한 검증을 대신하지 않는다.

요청한 시각화는 후보 코드·실행 파일·실제 렌더 증거를 갖춘 상태다. 전체 회귀 테스트 실패와 미확인 항목을 공개한 상태로 검토를 요청하며, 정상화 또는 구현 완료를 확정하지 않는다.
