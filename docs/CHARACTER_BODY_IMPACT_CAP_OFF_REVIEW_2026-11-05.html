추가 충격량 상한 임시 해제

이 문서는 수동 밀침의 과거 후보 기록입니다. 현재 후보는 실제 PhysX 캡슐 충돌 검토 보고서를 참고하세요.

2026-11-05 · 사용자 요청에 따른 실험 후보 · 미커밋

질량·관성 기반 추가 상한만 뺐습니다. 최종 적용량은 기존 min(180 × 배율 × 접근속도 / 3.5, 500) N·s입니다. 기존 500 N·s 설정, 최소 접근 속도, 상체 필터, 실제 맞은 바디 적용, 바디별 접촉 관리는 유지합니다. UI 설명도 현재 임시 상태로 맞췄습니다. 관절 토크 상한은 변경하지 않았습니다.

변경 직전 기준은 추가 상한을 적용한 이전 후보 보고서입니다. 공통 기반 HEAD는 a6444d114d0874cbaaa8c96752398c8f2137eaaa이며, before.patch와 candidate.patch의 해시로 미커밋 후보 전후를 구분합니다.

검증 조건과 결과

동일 Mixamo Idle/Walking/SlowRun, 동일 Mixamo.physics.json 22개 바디·약 73 kg, 기본 바닥 Y=0, 마찰 0.9/0.7, 중력 −9.81 m/s², TGS, dt=1/60 s, 720스텝=12 s입니다. 플레이어 수동 지지와 더미 자동 지지, 애니메이션 전환, PA·회복 제어를 유지했습니다. 2초 대기→3초 접근→2초 후퇴→2초 재접근→3초 정지 입력도 동일합니다. case3은 측면 달리기, case5는 같은 접근에 frame120에서 속도 15 m/s를 추가한 고속 충격입니다.

재현: ModelViewer.exe -bodyimpacttest <절대경로>/case3.txt -bodyimpactcase 3 -impactcapture <절대경로>/case3. case5는 번호만 5로 바꿉니다. 작업 디렉터리는 MiniEngine/ModelViewer입니다. 모두 숨김 프로세스로 실행했습니다.
