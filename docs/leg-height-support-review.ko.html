다리 기반 골반 높이 지지 — 후보 검토

2026-11-02 · 기준 58c0fa92df7a92d8bd1c8e23cadc44fc426c1795 · 최종 물리 후보 candidate-7 · 검토 승인 전

자동 Idle에서 골반의 직접 Y 모터를 끄고, 지지 다리의 IK 자세와 관절 보상 토크로 높이를 유지하도록 변경했다. 발딛기·접촉 상실·도달 한계에 따라 골반 목표를 낮추며, 공중 발의 궤적을 골반 수평 목표가 따라가지 않게 분리했다.

같은 기본 가슴 충격에서 진행 중 이동 목표 무효는 103프레임 → 0프레임, 착지는 5/6 → 1/1로 바뀌었다. 후보는 한 번 딛고 양발 지지와 Animation 상태로 돌아왔다. 외부 골반 Y 힘은 모든 비교 후보 실행에서 0N이다. 이것은 해당 시험 결과이며 모든 충격에서 발 멈춤이 사라진다는 보장은 아니다.

변경한 제어 흐름

  1. 애니메이션의 골반–발 상대 높이와 실제 바닥에 둔 발 목표로 기준 골반 높이를 구한다. 초기 발이 약간 떠 있을 때 그 공중 위치를 영구 지지 목표로 저장하지 않는다.
  2. 발딛기 거리 × 0.25, 접촉 상실 시 최대 8cm(0.15초 누적), 실제 수평 간격과 다리 길이에서 계산한 도달 높이 중 필요한 낮추기를 선택한다. 최대 낮춤 18cm, 낮춤 속도 0.5m/s, 복원 속도 0.25m/s, 다리 길이 여유 1cm.
  3. 접촉 중인 지지 다리에 골반 높이 오차를 상대 발 목표로 전달한다. 접촉을 잃은 다리는 바닥을 계속 찾는다. 이동발의 XZ/Y 궤적에는 이 보정을 넣지 않는다. 이륙·착지 때 실제 발로 목표 기준을 다시 잡는 차이가 가짜 목표 속도·가속도로 계산되지 않도록 드라이브 목표 이력을 초기화한다. 실제 바디 속도와 PD 제동은 유지한다.
  4. 지지 기준에서의 수평 자세 오차와 COM 속도 × 0.1초를 지지 다리 목표에 최대 6cm 반영한다. 발딛기 중에는 직전 양발 지지 기준을 유지한다. 착지 후에는 고유 각주파수 4rad/s의 임계 감쇠 응답으로 새 기준에 접근한다. 외부 골반 XZ 힘을 추가하지 않는다.
  5. 실제 접촉이 있는 지지 다리에만 예상 중량을 배분한다. 양발은 COM을 두 접촉점 사이에 투영한 비율, 한 발은 전 하중이다. 이 예상 지면 하중의 JᵀF를 역동역학에서 빼 관절 토크를 구한다. 이 힘을 바디에 직접 더하지 않는다. 측정 반력과 예상 하중은 별도 값이다.
  6. 높이 제어는 발딛기 목표가 무효여도 계속 계산한다. 기존 접촉 판정, 색상 표시, 20cm 레이, A/B 해제 조건, 착지 판정, 예측 0.6/0.6초, 발 이동 0.3초와 PA는 유지했다.

수동 골반 지지 및 비 Idle 경로는 기존 동작을 사용한다. 자동 Idle의 골반 회전 보조 토크도 유지된다. 외부 보조가 전혀 없는 완전한 자립 균형 제어로 바꾼 것은 아니다.

  • 기존 이동 시간 0.3초와 접촉 무효 시 목표 갱신 보류 코드는 유지했다. 다른 충격에서 지지 접촉을 잃으면 기존 보류 문제가 다시 나타날 수 있다. 이번 변경은 이 시험에서 접촉 상실의 원인을 줄인 결과다.
  • 일부 발·팔다리 목표 추종 지표는 기준보다 커질 수 있다. 의도한 골반 낮춤, 지지용 가상 발 목표와 실제 접촉 결과를 구분해 표에 모두 남겼다. IK 도달 가능만으로 정확한 발 자세 추종을 뜻하지 않는다.
  • 예상 하중은 정적 COM 배분이다. 경사면·계단·움직이는 발판, 반복 연속 충격, 다른 모델/PA/애니메이션은 검증하지 않았다. 통합 테스트의 다른 충격 강도에서는 A/B 가중치·해제 래치·낙하를 확인했지만 그 모든 조건의 변경 전후 상세 성능 비교는 수행하지 않았다.
  • 초기 후보 1~3은 무충격 상태에서 불필요한 스텝 또는 붕괴가 발생했다. 후보 4는 멈춤을 없앴지만 공중 발 목표를 골반이 따라가면서 4회 스텝과 약 47cm 이동이 생겼다. 후보 5의 수평 기준 유지와 후보 6의 감쇠 갱신에서는 별도 유한 토크 시험의 붕괴가 남았다. 후보 7은 이륙/착지 시 재설정한 목표를 가짜 속도·가속도로 해석하는 문제를 막았고 같은 포화 시험에서 한 번 착지한 뒤 회복했다. 실패 기록은 해당 후보 폴더에 남겼다.
  • 현재 범위의 구조 변경과 기본 바닥·기본 충격·별도 포화 조건은 검토 가능한 수준이다. 광범위한 균형 제어 완성이나 모든 발 멈춤 해결을 선언하지 않는다. AGENTS.md에 따라 사용자 검토 승인 전에는 구현 완료 확정이나 커밋을 하지 않는다.
