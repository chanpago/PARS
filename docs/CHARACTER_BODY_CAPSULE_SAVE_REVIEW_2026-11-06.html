캡슐 설정 저장 · 검토 후보

크기 아래 기존 버튼을 “캡슐 설정 저장/불러오기”로 명확하게 표시하고 크기·질량·충돌 사용 여부 저장 및 다음 실행 자동 적용 안내를 추가했습니다. 저장·불러오기 성공 메시지를 표시합니다.

저장 버튼 → CharacterImpactSettings::Save → CharacterImpact.settings.json(v4). 시작 시 LoadAnimationPreview → LoadBodyImpactSettings → SetSettings 경로는 이미 존재하며 같은 저장 파일을 적용합니다.

ModelViewer Debug x64 컴파일·별도 실행 파일 링크 성공. 기본 exe가 실행 중이라 일반 링크는 LNK1168이었고 별도 OutputFile로 성공했습니다(MSB8012 출력 이름 불일치 경고 2개). 현재 창을 닫아 파일 잠금이 풀리면 검증한 새 exe가 기본 이름에 적용되도록 숨김 작업을 예약했습니다. 실행 중인 프로그램은 종료하지 않았습니다.

--body-impact-only 통과: 저장/불러오기·높이 유지·이전 형식 이관 포함. 시작 시 로드는 소스 호출 경로를 확인했습니다. 마우스 클릭과 비기본 설정으로 재시작하는 별도 통합 검사는 실행하지 않았습니다.

물리식·파라미터·애셋 변경 및 물리 결과 비교는 없습니다. 기존 넘어짐·토크 제한 문제는 이번 변경 대상이 아닙니다. 사용자 승인 전 구현 완료 확정·커밋하지 않은 후보입니다.
