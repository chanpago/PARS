# COM 기반 골반 보조 지지 및 넘어짐 실험 계획

작성일: 2026-10-27

## 1. 목표와 진행 순서

절차적 발 디딤을 구현하기 전에, COM과 발의 지지 영역에 따라 골반의 보조 지지를 줄이는 규칙부터 검증한다.

```text
구 충돌 → 실제 Hips와 COM 이동
        → 지지 영역 A 이탈
        → 완충 영역 B 안에서 보조 지지 감소
        → B 이탈 시 보조 지지 해제
        → 물리 시뮬레이션으로 넘어짐
```

첫 실험은 평평한 바닥에 서 있는 비조종 Idle 더미를 대상으로 한다. 플레이어 조작과 달리기 판정은 후속 단계에서 다룬다.
자동 A/B 보조 지지까지 더미에 구현했다. 플레이어는 기존 수동 지지를 유지하고,
절차적 발 디딤과 쓰러진 뒤 일어서기는 후속 작업이다. 아래에는 설계 규칙과 검증 결과를 함께 기록한다.

## 2. 현재 준비된 기능

- 발 캡슐 콜라이더의 크기와 기준 자세로 발바닥 사각형을 만들고, 실제 발 바디의 위치·회전을 따라간다.
- 각 발의 네 꼭짓점에서 아래로 최대 20cm 레이를 쏜다. 자기 캐릭터와 트리거는 제외한다.
- 성공한 지면 투영점만 모아 XZ 평면의 convex hull을 만든다. 이것을 지지 영역 A로 사용한다.
- 실제 PhysX 바디의 질량과 월드 질량중심을 가중 평균해 전체 COM을 구한다.
- COM의 수직 투영점, A 내부·외부 판정, 디버그 표시가 있다.
- Idle 더미에 물리 구를 발사하고, 실제 Hips 위치와 최대 이동량을 확인할 수 있다.
- `SetRootSupported(bool)`는 수동 전체 지지, `SetRootSupport(weight, horizontal)`는 연속 강도와 X/Z 지지 여부를 설정한다.
- 더미는 기본적으로 COM 자동 지지를 사용한다. 자동 모드에서는 X/Z 지지가 없고 Y·회전만 계수에 따라 지원한다.

20cm 레이 판정은 근접한 바닥을 지지로 인정하는 실험용 근사다. PhysX의 실제 접촉점이나 하중을 측정한 결과와는 구분한다.

## 3. A와 B의 정의

### A: 현재 발의 지지 영역

양발의 유효한 지면 투영점을 감싸는 convex hull이다. 한 발만 유효하면 그 발의 점들로 만든다.
고유한 점이 세 개 미만이거나 모두 일직선이면 유효한 지지 다각형이 없는 것으로 처리한다.

### B: 보조 지지를 해제하는 완충 영역

A의 중심 `c`를 기준으로 A의 각 꼭짓점을 확대해서 만든다.

```text
λ = 2.0                         // 첫 실험의 기본 확대율
B[i] = c + λ × (A[i] - c)       // XZ 평면에서 계산
```

- `c`는 A의 면적 중심을 사용한다. 유효한 convex hull의 내부에 있는 점이다.
- 여기서 2배는 중심에서 경계까지의 **길이**가 2배라는 뜻이다. 면적은 4배가 된다.
- A가 이동하거나 모양이 바뀌면 중심과 B도 함께 갱신한다. 초기 월드 위치에 B를 고정하지 않는다.
- B는 보조 지지를 얼마나 남길지 결정하는 범위다. 실제 발의 접촉 면적은 A에 해당한다.

## 4. 거리 정규화와 보조 지지 계수

현재 COM의 바닥 투영점을 `p`라고 한다. 평평한 바닥에서는 XZ 좌표로 판정한다.

| COM 투영점의 위치 | 보조 지지 계수 `w` |
| --- | --- |
| A 내부 또는 A 경계 | 1 |
| A 경계와 B 경계 사이 | 거리에 따라 1에서 0으로 감소 |
| B 경계 또는 B 외부 | 0 |
| 유효한 A가 없음 | 0 |

A와 B 사이에서는 중심 `c`에서 `p` 방향으로 반직선을 그어 두 경계와의 교점을 구한다.

```text
qA = 같은 반직선과 A 경계의 교점
qB = 같은 반직선과 B 경계의 교점

d = |p - c|
a = |qA - c|
b = |qB - c|                    // 중심 확대 방식이면 b = λ × a

t = Clamp((d - a) / (b - a), 0, 1)
w = 1 - t
```

따라서 A 경계에서 100%, A와 B 경계의 중간에서 50%, B 경계에서 0%가 된다.
다각형의 방향별 폭을 사용하므로 발의 앞뒤와 좌우 폭 차이도 반영된다.

구현 시 지킬 조건:

- A 내부 판정을 먼저 수행한다. `p == c`이면 방향을 정규화하지 않고 `w = 1`을 사용한다.
- 확대율은 `λ > 1`로 제한하고, 퇴화한 다각형과 0에 가까운 분모를 처리한다.
- 첫 실험은 선형 감소를 사용한다. 경계에서 힘 변화가 거칠면 이후 `1 - SmoothStep(0, 1, t)`를 비교한다.
- 원시 계수와 실제 적용 계수를 따로 기록한다. 필터를 추가할 때도 계산 결과를 확인할 수 있게 한다.

## 5. 골반 제어에 적용할 항목

첫 더미 실험에서는 수평 이동을 허용하고, Y 높이와 골반 회전의 보조 지지를 A/B 규칙으로 줄인다.

| 제어 항목 | 첫 실험의 처리 |
| --- | --- |
| 고정된 월드 목표로 복원하는 골반 X/Z 위치 지지 | 비활성화 |
| 골반 Y 높이 지지 | `w`에 따라 감소 |
| 골반 월드 회전 지지 | `w`에 따라 감소 |
| 팔다리의 상대 관절 자세 PD | 유지 |
| PhysX 중력·충돌·관절 반작용 | 계속 시뮬레이션 |

Y 위치 모터는 기본 강성·감쇠·최대 힘을 보관하고, 같은 계수로 줄이는 방식부터 실험한다.

```text
KpY   = 기본 KpY   × w
KdY   = 기본 KdY   × w
FmaxY = 기본 FmaxY × w
```

목표 월드 Y 좌표에 계수를 곱하지 않는다. 줄일 대상은 목표를 추종하도록 가하는 보조 힘의 세기다.
최종 힘과 실제 변위는 PhysX의 풀이 결과로 확인한다.

골반 회전도 실제 PD 계수와 지원 토크에 계수가 반영되도록 한다.
PD 계산과 계산 후 토크에 계수를 중복으로 곱해 의도하지 않게 `w²`가 적용되지 않도록 한다.
`w = 0`에서는 몸을 월드 방향으로 다시 세우는 보조 토크도 남지 않아야 한다.

### 관성·추가 보상과의 연동

기존 articulation 경로는 `IsRootSupported()` 하나로 추가 보상과 자유축 계산을 결정했다.
현재는 지지 여부, 축별 지원 여부, 연속 강도를 구분한다.

- 지지가 존재하는지, 실제로 지원하는 축이 무엇인지, 세기가 얼마인지를 구분한다.
- `ControlInertias()`에 전달하는 자유축에 지원하지 않는 골반 축을 반영한다.
- 골반 회전 PD와 `G + C + M*a` 추가 보상에 같은 지원 상태를 사용한다.
- 골반 보정 가속도의 관절 반작용 계산에도 일관된 값을 사용한다. 골반 토크 한 곳만 사후에 줄여 끝내지 않는다.
- 완전히 해제된 상태에서는 골반 지지와 연동된 추가 보상 및 목표 속도 이력을 현재의 지지 해제 경로와 일관되게 정리한다.
- 일반 관절 PD까지 함께 꺼지지 않는지 확인한다.

`SetRootSupported(false)`는 전체 해제 경로로 재사용할 수 있지만, 부분 감쇠를 매번 bool 전환으로 처리하지 않는다.
수동 골반 지지 테스트와 자동 A/B 제어는 별도 모드로 둔다.

구현한 감쇠·연동 방식:

- Y 드라이브는 강성·감쇠·힘 상한을 `w`로 곱한다. 회전 PD도 강성·감쇠를 줄여 후진 오일러 분모까지 다시 계산한다.
- 목표 가속도 차분과 `G+C`는 각각 한 번씩 `w`를 적용한다. 이미 감쇠한 골반 PD 가속도를 포함한 `a`를 골반과 관절 행에 공통으로 사용한다.
- 자유축 F에서는 `M_FF*a_F = -w*(G+C)_F - M_FD*a_D`를 풀어 계산된 추가 보상이 그 축에 힘을 요구하지 않도록 한다. 접촉과 일반 관절 PD는 PhysX가 별도로 계산한다.
- X/Z는 처음부터 유효 관성의 자유축에 들어간다. 부분 지지 중에는 지원 상태와 전체 해제 상태의 유효 관성을 `w`로 선형 혼합해, 해제 순간 관절 PD 계수가 급변하지 않게 근사한다.
- 계수 변경만으로 목표 속도 이력을 지우지 않는다. 지원 축 변경이나 전체 해제 시에는 해당 이력을 초기화한다.
- 경과 시간 0으로 애니메이션 목표를 교체·초기화할 때도 속도 이력을 지워, 다음 스텝에 가짜 감속 보상이 생기지 않게 한다.
- `w=0`이면 지지 조인트와 추가 보상을 해제한다. 일반 관절 PD의 활성 상태는 유지한다.

## 6. 해제 후 재활성화 규칙

첫 실험에서는 B를 벗어나거나 유효한 A가 사라져 보조 지지를 해제하면, 초기화 전까지 해제 상태를 유지하는 안을 사용한다.

```text
지원 중:
    A 내부     → w = 1
    A와 B 사이 → 0 < w < 1
    B 도달/이탈 또는 A 무효 → 해제 상태로 전환

해제 상태:
    적용 w = 0 유지
    더미 초기화 → 상태와 물리 포즈를 함께 초기화
```

해제가 확정된 후에는 몸의 COM이 A 안으로 다시 들어와도 지지가 켜져 몸을 끌어올리는 현상을 막는다.
B에 도달하기 전에 A로 돌아오는 경우에는 계수 회복을 허용한다.
추가 지연 시간이나 자동 일어서기 규칙은 첫 버전에 넣지 않고, 측정 결과에 따라 후속 단계에서 결정한다.

## 7. 물리 갱신과 디버그 데이터

발 투영·COM·A/B·원시 계수 계산은 `FootSupport`로 분리했다.
`SkeletalMeshComponent::FixedTickComponent()`에서 드라이브 목표를 준비하기 전에 계산하고,
`FootSoleDebug`는 저장된 스냅샷만 읽는다. 메시/물리 초기화와 모드 전환 때도 스냅샷을 준비한다.
더미의 자동 모드에서는 이 스냅샷으로 골반 지원을 갱신한 뒤 애니메이션 드라이브 목표를 계산한다.
수동 모드에서는 스냅샷이 관측용으로만 사용된다. 실행 순서는 다음과 같다.

1. 마지막으로 완료된 물리 상태에서 실제 발 바디와 전체 COM을 읽는다.
2. 발 레이캐스트로 유효한 투영점과 A를 계산한다.
3. B와 COM의 위치 관계, 원시 계수, 해제 상태를 갱신한다.
4. 적용 계수로 골반 보조 지지와 관련 관성·보상 설정을 갱신한다.
5. PhysX를 시뮬레이션하고 결과를 받는다.
6. 계산과 결과를 저장해 디버그 화면에서 읽는다.

디버그 표시를 꺼도 제어 계산은 계속 실행되어야 한다. 렌더 FPS가 바뀌어도 물리 스텝의 계수 계산 순서는 같아야 한다.
초기화 시에는 첫 물리 스텝 전에 A와 계수 상태를 준비해 이전 실험 값이나 미계산 상태를 사용하지 않는다.

추가 표시할 항목:

- A 외곽선과 B 외곽선. B는 흰색 점선 등으로 기존 A와 구분한다.
- 전체 COM과 바닥 투영점. 기존 초록·빨강·검정의 의미는 유지한다.
- 원시 계수와 적용 계수, 지원 중/해제 상태.
- 중심에서 투영점까지 거리와 같은 방향의 A·B 경계까지 거리.
- 실제 Hips 위치, 목표 Y 높이와 오차, 발사 이후 최대 이동량.
- 현재 지원하는 축과 보조 지지 설정.

## 8. 구현 단계

- [x] A/B 생성 및 계수 계산을 공용 함수로 분리한다. 내부·경계·중간·외부·퇴화 입력을 검증한다.
- [x] 물리 스텝에서 계산한 A/B와 계수를 표시하는 모드를 추가한다. 이 단계에서는 기존 지지 동작과 수치를 비교한다.
- [x] 더미에만 자동 A/B 제어 모드를 추가한다. 플레이어의 이동 제어는 후속 단계로 남긴다.
- [x] X/Z 복원을 해제하고, Y·회전의 보조 지지 및 관련 관성·보상을 계수와 일치시킨다.
- [x] 지지 해제 상태 유지와 더미 초기화 처리를 구현한다.
- [x] 고정된 더미·발사 조건에서 Idle, 약한 충격, 감쇠 후 해제·넘어짐을 검증한다.
- [ ] 여러 충격 방향과 발바닥 설정을 직접 확인한 뒤 절차적 발 디딤 구현으로 진행한다.

첫 더미 실험에서 Actor·캡슐 추종 방식을 전부 개편할 필요는 없다. 고정된 부모 변환이 남아 있어도 실제 골반을 그 X/Z 위치로 되돌리는 힘이 남지 않아야 한다.
플레이어에 확장할 때는 물리 골반 이동을 Actor·캡슐 및 이동 입력에 반영하는 방식을 별도로 설계한다.

사용법:

- 기존 발바닥 UI에서 보라색 A, 흰색 점선 B, COM 위치 구간, 계산 계수 `w`를 확인한다.
- B 거리 배율의 기본값은 2.0이다. UI에서 배율과 발바닥 크기·위치를 바꾸면 다음 물리 스텝에 반영된다.
- 일시정지 중에는 마지막 스냅샷을 유지한다. 한 스텝 실행으로 변경된 설정의 판정을 확인한다.
- 더미 패널의 `COM 자동 골반 지지`가 기본으로 켜져 있다. 끄면 수동 전체 지지와 비교할 수 있으며, 모드 전환은 더미를 초기화한다.
- 원시 `계산 계수 w`와 실제 `적용 w`, 지원 축, 해제 원인을 확인한다. 완전히 해제되면 COM이 재진입해도 적용 계수는 0이다.
- 표시 여부와 계산·자동 제어는 독립적이다. 수동 모드의 계산 계수는 모터에 적용하지 않는다.
- 디버그는 다음 시뮬레이션을 준비할 때 읽은 실제 바디 상태를 표시하므로, 렌더링되는 최신 물리 포즈보다 한 고정 스텝 이전의 상태다.

## 9. 충격 실험과 통과 조건

더미 초기화, 고정 스텝 수, 발사 위치·방향, 구 질량·속도를 동일하게 맞춰 비교한다.
먼저 구를 쏘지 않은 Idle의 COM·골반 흔들림을 기준으로 기록한다.

현재 코드의 구 기본값은 반지름 15cm, 질량 50kg, 초기 속도 75m/s다.
실험마다 반지름·질량·속도를 기록하고, UI에서 질량·속도를 조정해 아래 상태에 도달하도록 한다.
특정 질량·속도가 항상 같은 영역 이탈을 만든다고 가정하지 않는다.

| 실험 | 통과 조건 |
| --- | --- |
| 충격 없는 Idle | A 내부에서 계수 1이 유지되고 초기 해제가 발생하지 않는다. |
| A 내부에 머무는 충격 | 실제 Hips가 물리적으로 이동하며 수평 월드 목표에 강제로 복원되지 않는다. |
| A와 B 사이로 이동 | 경계까지의 거리에 맞게 계수가 1에서 0으로 감소한다. |
| B 도달 또는 이탈 | Y·회전 보조 지지가 해제되고 몸의 후속 운동은 물리 시뮬레이션으로 진행된다. |
| 지지 해제 후 COM 재진입 | 초기화 전까지 지지가 자동 재활성화되지 않는다. |
| 한 발만 유효 | 남은 발의 A와 그에 대응하는 B로 판정한다. |
| 발 지지 영역이 사라짐 | 유효하지 않은 A를 이전 값으로 유지하지 않고 적용 계수 0으로 처리한다. |
| 일시정지 및 한 스텝 | 정지 중 값이 임의로 진행되지 않고 한 스텝마다 제어와 물리가 함께 진행된다. |
| 렌더 FPS 변경 | 같은 물리 시점의 계수와 상태 전환 결과가 일치한다. |
| 더미 초기화 | 구, 물리 포즈, 계수, 해제 상태와 목표 이력이 새 실험 기준으로 초기화된다. |

완료 기준은 **충격 → COM 이탈 → 보조 지지 감소 → 해제 → 넘어짐**이 연속적으로 관찰되고,
순간이동, 과도한 원위치 복원, 힘의 급격한 변화, 해제 후 자동 끌어올림이 발생하지 않는 것이다.

### 2026-10-27 자동 검증 결과

기본 발사 위치·방향, Idle 120스텝 준비, 발사 후 300스텝, 구 반지름 15cm에서 측정했다.
수치는 이 테스트 조건의 결과이며 다른 발사 방향이나 발바닥 설정에 대한 보장은 아니다.

| 실험 | 관찰 결과 |
| --- | --- |
| 자동 지지 Idle 10초 | 최소 적용 계수 1.0, 해제 없음 |
| 0.1kg / 30m/s | 계수 1.0 유지, 해제 없음, 발사 기준 최대 골반 이동 약 6.2cm |
| 2kg / 30m/s | 감쇠 구간 9스텝, 발사 후 인덱스 15 스텝에서 해제, 골반 높이 최저 약 9.6cm |
| 50kg / 75m/s | 발사 후 인덱스 2 스텝에서 해제, 골반 높이 최저 약 9.0cm |

감쇠 과정을 관찰할 때는 `2kg / 30m/s`부터 시작할 수 있다. 기본 `50kg / 75m/s`는 감쇠 구간을 빠르게 지나칠 만큼 강하다.
별도 검사에서 B 이탈·지지점 소실에 따른 해제, 재진입 시 해제 유지, 반복 활성화 호출로 재무장되지 않음, 리셋 복구를 확인했다.
D6와 articulation 모두에서 계수 감소에 따른 Y·회전 응답 감소, X/Z 복원력 없음, 해제 시 포즈·속도 보존을 검증했다.
기존 수동 골반 지지 및 래그돌 테스트도 통과했다.
계수 변경 시 목표 속도 이력 유지, 가속도 보상의 1회 감쇠, 목표 초기화 뒤 보상 가속도 제거도 별도 회귀 테스트로 검증했다.

## 10. 이후 절차적 발 디딤으로 확장

A/B 실험이 통과하면 발 디딤을 균형 회복 동작으로 추가한다.

```text
COM이 A를 벗어나려 함
→ COM 위치·속도와 발 상태로 디딜 방향·위치 결정
→ 발과 몸의 애니메이션 목표 수정
→ 관절 PD로 실제 발 바디 이동
→ 새 발의 유효한 지면 투영을 A에 반영
→ A/B 재계산 및 보조 지지 계수 회복 여부 관찰
```

첫 발 디딤 구현은 보조 지지가 완전히 해제되기 전에 A를 옮겨 COM을 다시 받아내는 것부터 검증한다.
이 단계에서 실패 후 재지지·일어서기 정책을 별도로 검토한다.
달리기와 공중 동작에서는 COM 위치 외에 속도와 다음 착지를 함께 다뤄야 하므로, Idle 실험의 통과 조건을 그대로 적용하지 않는다.
