# 공 피격 시 전신에 더하는 선형 충격량 구현 계획

2026-11-24 · 구현 전 설계안

공이 머리에 맞으면 PhysX가 머리의 실제 접촉점에 충격을 준다. 여기에 **맞은 캐릭터 전체가 같은 방향으로 더 밀리는 양**을 별도로 조절할 수 있게 한다. 추가분은 모든 물리 바디에 같은 선속도 변화를 주는 방식으로 만든다. 이후 몸이 기울거나 발을 옮기는 움직임은 실제 접촉, 관절과 발 지지에서 나온다.

## 1. 추가로 얼마나 밀 것인가

레퍼런스의 피격 노드는 부위 충격량과 전신 충격량을 별도로 받는다. 전신 이동의 기준값은 전신 충격량을 총질량으로 나눈 속도다. PARS에서도 이 계산을 사용하되, 공의 질량과 속도에 맞춰 강도가 따라가도록 **실제 전달된 충격량에 곱하는 배율**을 첫 조절값으로 제안한다. [레퍼런스의 피격 입력](../../NaturalMotion-MorphemeRuntime-5.2/morpheme/SDK/euphoriaCore/src/Nodes/erNodeOperatorHit.cpp#L766) · [전신 이동 계산](../../NaturalMotion-MorphemeRuntime-5.2/morpheme/SDK/physics/src/PhysX3/mrPhysicsRigPhysX3.cpp#L378)

```text
J_hit = sum(J_contact)
J_extra = gain * J_hit
delta_v = J_extra / M
```

- `J_contact`는 피격자가 받은 방향으로 부호가 정해진 월드 공간의 접촉 충격량 벡터(N·s)다. 같은 공이 처음 충격을 준 물리 스텝의 유효한 접촉점들을 벡터로 합산한다. 빗맞거나 비스듬히 들어온 경우도 수직 성분을 포함한 실제 전달 방향을 따른다.
- `gain`은 무차원 배율이다. 더미 UI 이름은 **전신 추가 밀림 배율**, 초기값은 `0`, 조절 범위는 `0~1`로 제안한다. `0`이면 추가 이동량이 0이고, `1`이면 최초 접촉에서 측정한 선형 충격량만큼 전신 이동을 한 번 더 보탠다.
- `M`은 맞은 캐릭터의 래그돌 물리 바디 질량 합계(kg), `delta_v`는 전신에 공통으로 더할 속도 벡터(m/s)다. 예를 들어 총질량이 80 kg이고 오른쪽으로 40 N·s를 받았다면, 배율 `0.5`에서 추가분은 오른쪽 20 N·s, 속도 변화는 0.25 m/s다.

질량이 `m_i`인 바디가 받는 추가 운동량은 `m_i * delta_v`다. 전부 더하면 정확히 `J_extra`이고, 전신 질량중심 기준의 추가 각운동량은 0이다. 같은 충격 벡터라면 머리와 골반 중 어디를 맞아도 **추가 밀림**은 같다. 부위별 차이는 원래 접촉점에서 생긴다.

## 2. 어느 물리 스텝에 한 번 적용할 것인가

| 피격 시 상태 | 적용 시점 |
|---|---|
| 이미 동적인 래그돌 | 완료된 스텝의 공 접촉을 읽는 첫 고정 틱에서 전신 속도만 더한다. 국소 충격은 직전 PhysX 스텝에서 이미 전달됐다. 액티브·패시브 모두 동적이면 이 경로를 쓴다. |
| 키네마틱 더미가 실제 접촉 후 액티브로 전환 | 전환 전에 복사한 접촉을 `ReplayKinematicImpacts()`에 넘긴다. 이 함수가 원래 국소 충격을 재생하는 **같은 고정 틱**에 전신 속도도 한 번 더한다. |
| 공의 접근을 예측해 접촉 전에 전환 | 전환 시점의 추가분은 0이다. 이후 첫 실제 충격이 기록되면 동적 경로에서 처리한다. |
| 캐릭터 캡슐 충돌로 발딛기 예열 중 공에 맞음 | `FinishImpactWarmup()`이 확보한 접촉 중 공의 충격만 같은 재생 경로로 보낸다. 예열에서 상속한 캡슐 속도는 별도 입력으로 둔다. |

현재 동적 경로는 `FixedTickComponent()`, 전환 경로는 `ReplayKinematicImpacts()`에 모인다. 두 경로가 같은 전신 밀림 처리 함수를 호출하도록 한다. 적용 시점은 렌더 프레임과 독립적이며, 추가 지연 타이머는 필요하지 않다. [고정 틱](../MiniEngine/Model/Components/SkeletalMeshComponent.cpp#L190) · [키네마틱 충격 재생](../MiniEngine/Model/Components/SkeletalMeshRecovery.cpp#L466) · [예열 종료 경로](../MiniEngine/Model/Components/SkeletalMeshImpactWarmup.cpp#L376)

### 같은 공이 머리와 목에 걸친 경우

현재 `newProjectileHit`는 **두 충돌 형상의 쌍**에서 처음 충격이 생긴 스텝을 표시한다. 한 공이 머리에서 목으로 계속 닿으면 새 형상 쌍이 생길 수 있다. 전신 밀림의 단위는 **공 하나와 캐릭터 한 명이 연속으로 접촉한 구간**으로 정한다. [접촉 쌍 기록](../MiniEngine/Core/PhysicsWorld.cpp#L156) · [피격자가 받은 충격 벡터](../MiniEngine/Core/PhysicsWorld.cpp#L401)

1. 물리 월드에서 발사체 수명 동안 유효한 식별자를 접촉 기록에 실어, `PhysicsContactImpulse`에서 `RagdollBodyImpulse`와 전환 시 복사본까지 전달한다. 피격자별로 공을 구분하고 첫 유효 스텝의 여러 접촉점을 먼저 합친다.
2. 그 접촉 구간의 첫 충격을 한 번 소비한다. 같은 스텝 재호출, 다음 스텝의 지속 접촉, 접촉 중 부위 변경은 이미 소비한 구간으로 처리한다. 배율은 이때 읽어 두어 접촉 도중 UI를 바꿔도 지난 충격이 다시 나오지 않게 한다.
3. 모든 형상의 접촉이 끝나고 같은 공이 튕겨 돌아와 다시 맞으면 새 피격이다. 키네마틱 전환에 따른 접촉 캐시 초기화는 실제 분리와 구별하고, 잠든 접촉은 콜백이 생략될 수 있으므로 월드의 접촉 기록에서 종료를 확인한다. 공 제거·더미 초기화·월드 시계 리셋 때는 해당 식별 기록을 정리한다. 동시에 맞은 서로 다른 공은 각각 계산해 벡터로 합친다.

## 3. 코드에 연결할 순서

1. **물리 접촉을 수집한다.** `Ragdoll::GetExternalImpacts()`의 `fromProjectile`과 수신 측 `impulse`를 사용한다. 바닥·자기 몸·캐릭터 캡슐은 추가분의 입력에서 제외한다. 기존 관절 반응은 같은 원본 접촉을 계속 읽게 하고, 전신 밀림의 소비 기록만 따로 둔다. [래그돌 접촉 수집 및 기존 반응](../MiniEngine/Model/RagdollImpact.cpp#L27)
2. **전신 속도를 적용한다.** `GetCenterOfMass()`가 반환하는 총질량으로 나눠 기존 `Ragdoll::AddVelocity(delta_v)`를 한 번 호출한다. 이 함수는 D6에서는 동적 바디마다 같은 속도 변화를 주고, Articulation에서는 루트 선속도를 더한 뒤 링크 속도를 갱신한다. 관절 드라이브를 켰는지와 독립적으로, 실제로 시뮬레이션 중일 때만 적용한다. 유효한 충격이 없거나 합이 0이거나, 질량·입력·결과가 유한하지 않거나 질량이 0 이하이면 추가분은 건너뛴다. [전신 질량](../MiniEngine/Model/Ragdoll.cpp#L690) · [공통 선속도 적용](../MiniEngine/Model/Ragdoll.cpp#L846)
3. **더미에서 조절한다.** 배율은 피격 대상의 `SkeletalMeshComponent` 설정으로 두어 같은 더미를 리셋해도 비교값을 유지한다. `PARS - 더미 충격 테스트`의 슬라이더와 자동 검증용 `-impactpushscale` 옵션은 같은 설정을 사용한다. 유한한 입력값은 `0~1`로 제한하고, 유효하지 않은 입력은 기존 값을 유지한다. [더미 UI](../MiniEngine/ModelViewer/RagdollImpactTest.cpp#L563) · [피격 시나리오 입력](../MiniEngine/ModelViewer/RagdollImpactValidation.cpp#L419)

## 4. 완료 판정

| 검증 | 통과 조건 |
|---|---|
| 자유 공간에서 배율 0과 0.5 비교 | 같은 자세와 국소 충격을 재현하고 중력·감쇠·드라이브를 끈다. 지면이나 공과의 후속 접촉 없이 추가분을 적용한 스텝을 마치면, 두 실행의 질량중심 속도 차이는 `delta_v`다. 바디 간 상대 선속도와 각 바디의 각속도는 두 실행에서 수치 오차 내로 일치한다. D6와 Articulation에서 각각 확인한다. |
| 머리·골반 피격 및 전환 | 같은 공과 조준으로 배율 0·0.25·0.5를 비교한다. 첫 국소 충격량, 추가 충격 벡터, 총질량, 적용 스텝·횟수를 기록한다. 이미 동적인 상태와 키네마틱 전환 모두 피격당 1회이며 배율 0의 움직임은 변경 전 기준과 일치한다. |
| 중복·재피격 | 한 공의 다중 접촉점·머리에서 목으로 이어지는 접촉은 1회, 실제로 떨어졌다 다시 맞으면 2회다. 두 공이 동시에 준 충격량의 크기가 같고 방향이 반대라면 전신 추가분의 합은 0이다. 공과 동시에 닿은 캐릭터 캡슐의 충격은 계산에서 제외한다. |
| 서 있는 더미 | `-bodyimpacttest` 머리 조준으로 강·약 피격을 재생한다. 발 접촉과 자세 제어가 개입한 최종 이동거리는 관찰값으로 기록하고, 입력의 정확성은 자유 공간 속도 검사로 판정한다. 실제 접촉 없이 접근만 한 경우 적용 횟수는 0이다. |
