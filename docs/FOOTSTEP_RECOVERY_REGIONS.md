# 일반·교차 딛기 선택과 영역 디버그

실제 COM과 속도로 계산한 회복 영역을 일반·앞 교차·뒤 교차 도달 영역과 비교한다. 일반 영역과 겹치면 일반 딛기를 우선하고, 일반 영역과 겹치지 않으면 앞뒤 중 겹침 면적이 큰 영역을 선택한다. 어느 영역과도 겹치지 않으면 가장 가까운 후보를 최선 시도로 남긴다.

근거는 [Reachability Aware Capture Regions with Time Adjustment and Cross-Over for Step Recovery](https://arxiv.org/html/2307.11968v1)의 Ⅱ·Ⅳ·Ⅴ절이다. 이번 구현은 고정된 착지 시간의 LIP 모델과 제한된 후속 스텝 근사를 사용한다. 논문의 전신 제어기와 시간 최적화 전체를 구현한 것은 아니다.

## 실행 순서

1. `FootSupport`가 실제 COM·속도·양발 접촉과 PA 바디 자세를 수집한다.
2. `FootstepPlanner`가 기존 일반 착지 후보와 이동발을 계산한다.
3. `MakeRecoveryTarget`이 보정 전 실제 COM·속도로 `SelectFootstepRecovery`를 호출한다. 시작/착지 COM 제한 결과는 회복 영역 계산에 사용하지 않는다.
4. 일반 딛기는 회복 영역과 일반 도달 영역의 교집합에서 넓은 조각의 중심부터 착지 자세를 검사한다. 처음 통과한 지점을 그대로 착지 목표로 사용한다. 교차 후보에는 일반 분기의 COM 방향 제한·최소 발 간격을 다시 적용하지 않는다.
5. `FootstepLandingQuery`가 최대 6개 후보의 두 뼈 IK, PA 관절 제한, 반대 다리와의 3×3 형상 겹침을 검사한다.
6. 기존 하중 인계와 실제 이륙 확인을 거쳐 발 목표를 갱신한다.
7. 캐릭터별 `FootstepSettings::pathAvoidanceEnabled`는 기본값이 꺼짐이다. **발딛기 판단 / 착지 목표 → 이동 경로 충돌 예측 및 우회**를 켜면 IK 적용 직전에 `FootstepAvoidance`가 양쪽 다리의 이동 경로를 검사하고 필요하면 우회 후보를 찾는다. 경로가 거절되거나 미확인이면 다음 틱의 착지 후보 선택에 반영한다. 끄면 다음 물리 틱부터 기본 발 궤적과 IK로 발을 옮긴다.

새 착지 후보를 확보하지 못하면 기존 일반/진행 중 목표를 유지하며 성공으로 표시하지 않는다. 판단 결과와 기존 회피 결과를 함께 확인해야 한다.

## 물리 모델

수평 벡터는 XZ 성분이며 `h`는 지면에서 COM까지의 현재 높이다.

```text
omega = sqrt(9.81 / h)
icp = com_xz + velocity_xz / omega
growth = exp(omega * firstStepTime)
futureICP = growth * icp + (1 - growth) * supportCoP
```

`supportCoP`가 실제 지지발 사각형 안에서 선택될 수 있다고 가정한다. 이동발이 착지한 후의 발바닥 크기도 반영하여, 미래 ICP를 발바닥으로 받을 수 있는 발 중심 위치의 집합을 만든다. 단일 점이나 COM의 직선 예측과 구분된다.

기본 예측 범위는 3스텝이다. 2·3스텝에서는 지지발을 번갈아 바꾸며 후속 스텝을 역방향으로 계산한다. 마지막 전개에서는 이번 이동발에 필요한 영역만 구한다. `E_s`는 지지발 중심에 대한 허용 ICP 오차 집합, `D_s`는 다음 발의 상대 도달 영역, `S_s`는 현재 지지발의 상대 발바닥 영역이다.

```text
discount = exp(-omega * followingStepTime)
E_s_next = S_s ∪ (discount * (D_s + E_other) + (1 - discount) * S_s)
```

집합의 `+`는 두 집합에서 한 점씩 더해 만드는 민코프스키 합이다. 일반·앞 교차·뒤 교차 조각 사이를 임의로 볼록화하지 않는다. 겹침 면적은 합집합의 면적으로 계산하여 중복 조각이 선택 결과를 부풀리지 않게 한다.

뷰어에서 1스텝을 선택하면 초록색 영역은 1스텝 다각형의 꼭짓점 평균을 중심으로 가로·세로를 각각 1.25배 확장한다. 먼저 원래 영역과 도달 영역의 교집합에서 착지 후보를 검사한다. 후보를 확보하지 못하면 같은 자세 검사 예산 안에서 확장 영역과 도달 영역의 교집합을 사용한다. 확장분에서 고른 목표는 최선 시도로 기록하고 실제 착지 후 다시 판단한다. 배율 1.0은 원래 1스텝 모델을 사용한다.

첫 착지까지의 시간에는 이륙 전 들기 시간과 하중 이동 시간 추정을 포함한다. 이륙 후에는 실제 발딛기 시계의 남은 시간을 사용한다. 후속 스텝 시간에는 스윙·들기·하중 확인 시간을 포함한다. 선택한 목표의 최소 필요 스텝 수를 별도로 기록하고, 실제 착지와 하중 인계 뒤 다음 발의 후보를 다시 평가한다.

## 도달 영역과 PA 검사

- 도달 영역은 현재 고관절 높이, 스켈레톤의 허벅지·종아리 길이, 발목과 발바닥 사이 오프셋, 발 형상 크기, 최대 이동 거리에서 만든 12각형 근사다.
- 일반 영역에는 기존 최소 발 간격과 교차 억제 경계를 적용한다.
- 앞뒤 교차 영역에는 발 크기와 별도의 대각선 경계를 적용한다. 경계 각도는 기본 20도/30도이며 UI에서 조절할 수 있다. 이 값이 PA로부터 자동 최적화되는 것은 아니다.
- 색칠된 영역 전체가 PA 관절 한계와 자기 충돌까지 증명된 집합은 아니다. 선택 후보마다 실제 PA 관절 제한과 허벅지·종아리·발 형상을 검사한다. 관절 제한 판정은 기존 경로 검사와 같은 함수를 사용한다.
- 현재 골반을 고정했을 때 도달 범위가 없으면 교차 영역을 만들어내지 않는다. 골반 이동을 최적화하거나 고관절·무릎 굽힘 방향을 별도로 탐색하는 기능은 포함하지 않는다.

## 갱신과 표시

- 양발 Idle에서는 실제 발 위치를 기준으로 영역만 미리 본다. 자세 후보 탐색과 이동 명령은 실행하지 않는다.
- 키네마틱 Idle에서 발바닥과 바닥 사이의 미세한 간격 때문에 실제 접촉이 없으면, 레이로 얻은 지면을 미리보기에만 사용한다. 활성 물리 중 교차 판단에는 실제 지지발 접촉을 요구한다.
- 발딛기 시작과 진행 중에는 매 물리 틱 상태를 갱신한다. 75% 이후에는 기존 수평 목표 고정 규칙을 유지하면서 위험을 표시한다.
- 더미 발 디버그의 `회복·일반·교차 영역 색칠`로 표시 여부를 바꾼다. 표시는 시뮬레이션 판단과 독립적이다.
- 검정은 고관절 위치, 다리 길이, 발목 오프셋으로 구한 지면 도달 원에서 지지발 옆 최소 간격을 제외한 영역이다. 이 도형은 대기 중과 스윙 중에 모두 표시되며, 초록과의 겹침이 없거나 착지 자세가 거절된 틱에도 볼 수 있다. 플래너는 여기에 출발점 기준 최대 보폭을 적용한 뒤 UI에 표시할 겹침 면적과 실제 착지 후보를 구한다.
- 연초록은 탐색에 쓴 회복 영역이며, 1스텝에서는 확장분도 포함한다. 연주황과 연보라는 앞·뒤 교차 도달 영역, 흰 점은 선택한 착지점이다. 확장분에서 고른 목표는 UI에 따로 표시한다. 초기 Idle 미리보기는 왼발을 이동발로 가정한다.
- UI와 화면 상단의 `[딛기 명령]`에는 실제 이동 중인 발과 그 발의 일반·앞 교차·뒤 교차 모드를 표시한다. `[착지 탐색]`에는 이번 틱의 후보 검사 결과와 계산 시간을 표시한다. 진행 중에 모든 후보가 거절되면 명령에는 기존 모드와 `기존 목표 유지`가, 탐색에는 `착지 자세 검사 실패`가 뜬다. 이동 경로 검사 결과는 그 아래에 표시한다.

## 가정과 한계

회복 영역은 COM 높이와 캐릭터 방향이 유지되고 발 안의 압력 중심을 선택할 수 있다는 LIP 모델의 결과다. 현재의 PD 구동기가 그 압력 중심을 정확히 실현한다는 보장은 없다. 2·3스텝의 도달 범위는 현재 범위가 새 지지발에 대해 옮겨진다고 근사하며, 미래 골반과 장애물을 전신 시뮬레이션하지 않는다. 실제 착지마다 다시 계산한다.

이번 영역 선택은 수평 지면에서 동작한다. 경사진 지면이나 지지발 접촉이 없는 경우는 기존 계산으로 돌아간다. 착지 후보의 자기 충돌 검사는 반대 다리 세 부위이며 환경 장애물이나 새 착지면을 검색하는 지형 계획기는 추가하지 않는다. 실제 물리 추종 오차와 외력 때문에 검증한 목표 경로와 실제 바디 경로는 달라질 수 있다.

## 검증

`FootstepRecoveryTests.cpp`는 다각형 교집합·중복 없는 합집합 면적, 일반/앞/뒤 선택, 보정 목표로부터의 독립성, 도달 불가·PA 거절·목표 잠금, 유한 발 크기의 해석적 ICP 전개, 하중 이동 시간, 회전한 캐릭터 방향, 기존 플래너 연결을 검사한다. 기존 발딛기·IK·연속 충돌·서 있기 회귀 검사도 함께 실행한다.

실제 캐릭터 테스트의 `*.landing-com.csv`에는 판단 방식·상태·겹침 면적·자세 검사 수·판단 시간·경로 거절 여부와 확장분 선택 여부(`target_in_capture_margin`)가 기록된다. `-footsteprecovery 0`으로 기능을 끈 비교를, `-footsteprecoverysteps 1..3`으로 예측 범위를, `-footstepcapturescale 1.25`로 1스텝 확장 배율을 지정할 수 있다. 균형 복귀와 다리 접촉은 실제 착지·복귀 및 접촉 기록에서 확인한다.
